# Sudoku

A simple Sudoku game that runs directly in the browser. Built with plain HTML, CSS and JavaScript – no frameworks, no dependencies, no server.

## Getting Started

Open `index.html` in a web browser. No installation or internet connection required.

## Features

- Generate new puzzles with exactly one solution (Easy, Medium, Hard)
- Highlighting of rule violations
- Hints for empty cells
- Timer and points per solved puzzle
- Multiple players with saved settings and total score
- Visual styles: Light, Dark and X-Mas

Player data is stored locally in the browser (`localStorage`).
